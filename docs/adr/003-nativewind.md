# ADR 003 — NativeWind

## Status

Aceito.

## Contexto

O app precisa de UI customizada para telas fitness, como treino ativo, pace, timer e progresso.

## Decisão

Usar NativeWind com componentes próprios.

## Motivos

- Familiaridade com Tailwind.
- Boa produtividade.
- Flexibilidade visual.
- Evita dependência visual forte de biblioteca pronta.

## Consequências

- Mais responsabilidade na criação de componentes base.
- Design system próprio precisa ser mantido.
