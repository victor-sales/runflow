# Prompt 01 — Bootstrap e estrutura inicial

Use este prompt no Codex.

```txt
Leia o spec.md e o AGENTS.md.

Implemente apenas a Fase 1 do projeto.

Requisitos:
- manter TypeScript;
- configurar estrutura de pastas dentro de src;
- configurar ou ajustar Expo Router;
- criar telas iniciais:
  - Home
  - Escolha do tipo de treino
  - Corrida Livre
  - Lista de Treinos Intervalados
  - Criar Treino Intervalado
  - Histórico
  - Configurações
- criar componentes base:
  - Button
  - Card
  - AppText
  - Screen
  - MetricCard
- não implementar GPS;
- não implementar SQLite;
- não implementar treino intervalado;
- não adicionar backend;
- não adicionar autenticação.

Ao final:
- liste arquivos criados/alterados;
- explique como testar;
- rode lint se possível.
```
