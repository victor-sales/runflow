# Prompt 16 — Revisão técnica

Use este prompt no Codex.

```txt
Leia o spec.md e o AGENTS.md.

Faça uma revisão técnica do projeto.

Procure por:
- uso indevido de any;
- regra de negócio dentro de componentes React;
- SQL fora dos repositories;
- cálculos duplicados;
- arquivos muito grandes;
- problemas de tipagem;
- componentes com responsabilidade excessiva;
- inconsistências com o spec.md;
- dependências desnecessárias.

Não reescreva o app inteiro.
Faça ajustes pequenos e seguros.
Explique cada alteração.

Ao final:
- liste problemas encontrados;
- liste problemas corrigidos;
- liste problemas que recomenda deixar para depois.
```
