# Prompt 02 — Configurar NativeWind

Use este prompt no Codex.

```txt
Leia o spec.md e o AGENTS.md.

Configure NativeWind no projeto Expo com TypeScript.

Requisitos:
- instalar e configurar NativeWind;
- configurar Tailwind/CSS conforme necessário;
- configurar Metro conforme necessário;
- criar arquivo de tipos do NativeWind para TypeScript;
- aplicar estilos básicos nos componentes:
  - Button
  - Card
  - Screen
  - AppText
  - MetricCard
- manter a UI simples e funcional;
- não adicionar React Native Paper, gluestack-ui ou Tamagui;
- não alterar regras de negócio.

Ao final:
- liste arquivos alterados;
- explique como validar;
- rode lint se possível.
```
