# Prompt 10 — Histórico

Use este prompt no Codex.

```txt
Leia o spec.md e o AGENTS.md.

Implemente o histórico de treinos.

Telas:
- src/app/history/index.tsx
- src/app/history/[id].tsx

Requisitos:
- listar treinos concluídos;
- ordenar por data mais recente;
- exibir data, tipo, distância, duração e pace médio;
- abrir detalhe do treino;
- buscar pontos do treino;
- buscar segmentos se existirem;
- permitir excluir treino;
- usar WorkoutRepository;
- não executar SQL diretamente na tela;
- não implementar mapa ainda, apenas resumo textual.

Ao final:
- liste arquivos alterados;
- explique como testar criando uma corrida livre e abrindo no histórico.
```
