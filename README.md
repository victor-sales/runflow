# RunFlow

Aplicativo mobile local-first para monitoramento de corrida e execução guiada de treinos intervalados.

## Stack

- React Native
- Expo
- TypeScript
- Expo Router
- NativeWind
- SQLite local
- Zustand
- React Hook Form
- Zod

## Documentação principal

- `spec.md`: fonte da verdade do produto.
- `AGENTS.md`: regras de engenharia para Codex/agentes.
- `docs/architecture`: decisões e detalhes técnicos.
- `docs/adr`: decisões arquiteturais.
- `docs/prompts`: prompts por etapa para uso com Codex.

## Ordem recomendada

1. Criar projeto Expo com TypeScript.
2. Copiar estes arquivos para a raiz do projeto.
3. Seguir os prompts em `docs/prompts`.
4. Trabalhar em branches pequenas.
5. Validar com lint, testes e dispositivo físico.
